# Task Manager

A simple task management web app where users can add, edit, complete, delete and filter their daily tasks. Tasks are saved in the browser, so they stay even after refreshing the page.

![Task Manager Screenshot](screenshot.png)

## Features
- Add tasks with a priority (Low / Medium / High) and an optional due date
- Mark tasks as completed
- Edit and delete tasks
- Filter tasks by All, Pending or Completed
- Live count of pending and total tasks
- Data persists using browser localStorage

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS, DOM manipulation, localStorage)

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/yashika320/task-manager.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).
